# 拉夯了

上传图片并拖入不同梯队，按自己的标准排出一张可保存的排名图。图片不会上传到服务器。

## 本地运行

```sh
pnpm install
pnpm dev
```

## GitHub Pages

将仓库默认分支设为 `main`，在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。向 `main` 推送后，工作流会构建并发布 `dist`。Vite 会依据 `GITHUB_REPOSITORY` 自动设置项目站点路径。

## 使用

- 添加图片后拖入梯队；将图片拖回“待排图片”即可取消分级。
- 待排图片默认收起。点击左侧箭头可展开并删除误上传的图片。
- 点击“开始发牌”后，按“每次显示”的数量逐批显示图片；图片拖入梯队后会立即补充下一张。
- 通过齿轮编辑梯队名称、颜色，或添加、删除梯队。
- 导出标题可编辑；点击“保存排名图”下载 PNG。
- 所有状态保存在当前页面内存中。刷新或关闭页面后需要重新添加图片。
